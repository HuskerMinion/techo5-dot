# Packages the running system wants that the rescue initramfs does not. They are unpacked into the
# root filesystem only (apks-rootfs-dot/), because the initramfs is flashed to a partition with a size
# of its own and everything in packages-rescue.txt lands in both.
#
# tzdata: the zone database. Without it a time zone can only be followed from Home Assistant - the
# setup page's list of regions and zones is read out of /usr/share/zoneinfo, and a device that has
# never paired has no way to say where it is.
tzdata-2026d-r0.apk
#
# AirPlay (the daemon's feature/streaming): shairport-sync, and avahi to announce it, with what they
# need that the rescue and Bluetooth sets do not already carry. Spotify Connect is the daemon's own
# helper binary (bin/techo5-librespot, built by techo5's tools/linux/build-librespot.sh) and needs only avahi.
shairport-sync-5.0.4-r0.apk
avahi-0.9_rc4-r0.apk
avahi-libs-0.9_rc4-r0.apk
libdaemon-0.14-r6.apk
libevent-2.1.13-r0.apk
libcap2-2.78-r0.apk
libconfig-1.8.2-r0.apk

soxr-0.1.3-r7.apk
libgomp-15.2.0-r5.apk
